# CreateClub

# CreateClub(object, object)
Spawns in a magical weapon suited for that class as part of the random treasure distribution. 
void CreateClub( object oTarget, object oAdventurer);
#### Parameters
_oTarget_
Object to create item on. 
_oAdventurer_
A player object. 
#### Description
Creates a club in a container as part of the treasure distribution. 
#### Remarks
Found in nw_o2_feat.nss This can be used to create the item in any object with an inventory.

#include " nw_o2_feat "
