# SetTileAnimationLoops(location, int, int, int)

Set the state of the tile animation loops of the tile at location locTile. 
void SetTileAnimationLoops( location locTile, int bAnimLoop1, int bAnimLoop2, int bAnimLoop3);
#### Parameters 

locTile
    The tile location to query the tile ID. 

bAnimLoop1
    The on/off state to set for the first animation Loop of the target tile, if supported. 

bAnimLoop2
    The on/off state to set for the second animation Loop of the target tile, if supported. 

bAnimLoop3
    The on/off state to set for the third animation Loop of the target tile, if supported.
#### Description
Set the state of the tile animation loops of the tile at location locTile.
