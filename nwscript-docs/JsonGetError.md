# JsonGetError(json)

Returns the error message if the value has errored out. 
string JsonGetError( json jValue);
### Parameters 

jValue
    The json to analyze for errors.
#### Description
Returns the error message if the value has errored out. 
#### Remarks
Currently only describes parse errors.
