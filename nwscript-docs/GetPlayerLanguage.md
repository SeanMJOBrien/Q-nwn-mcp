# GetPlayerLanguage(object)

Returns the PLAYER_LANGUAGE_* code of the given player, or -1 if unavailable. 
int GetPlayerLanguage( object oPlayer);
### Parameters 

oPlayer
    Player object from whom to query language
### Description
Returns the PLAYER_LANGUAGE_* of the given player, or -1 if unavailable. 
### Version
This function was added in 1.85.8193.31 of NWN:EE.
