# GetLocalJson(object, string)

Get oObject's local json variable sVarName. 
json GetLocalJson( object oObject, string sVarName);
### Parameters 

oObject
    object to read a json variable from 

sVarName
    json variable name to read
#### Description
Get oObject's local json variable sVarName. 
#### Remarks
Return value on error: json null type.
