# GetGender(object)
Determines the gender of a creature. 
int GetGender( object oCreature);
#### Parameters 

oCreature
    The creature to check the gender of.
#### Description
Returns the gender (GENDER_*) of oCreature or -1 on error (invalid object/not a creature).

1.22
