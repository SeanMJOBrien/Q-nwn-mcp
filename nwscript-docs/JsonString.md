# JsonString(string)

Create a json string value. 
json JsonString( string sValue);
### Parameters 

sValue
    The string to create in json.
#### Description
Create a json string value. 
#### Remarks
NB: Strings are encoded to UTF-8 from the game-local charset.

This function was added in 1.85.8193.31 of NWN:EE.
