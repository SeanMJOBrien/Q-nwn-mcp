# GetPortraitResRef

# GetPortraitResRef(object)
Gets the portrait ResRef of the object. 
string GetPortraitResRef( object oTarget);
#### Parameters
_oTarget_
The object for which you are getting the portrait ResRef. 
#### Description
Gets the portrait ResRef of oTarget.The portrait ResRef will not include a trailing size letter.
