# CreateDart

# CreateDart(object, object)
Spawns in a magical weapon suited for that class as part of the random treasure distribution. 
void CreateDart( object oTarget, object oAdventurer);
#### Parameters
_oTarget_
Object to create the item in 
_oAdventurer_
A player object. 
#### Description
Creates a Dart as part of the treasure distribution system. 
#### Remarks
Found in nw_o2_feat.nss This can be used to create the item in any object with an inventory. 
#### Requirements
#include " nw_o2_feat "
