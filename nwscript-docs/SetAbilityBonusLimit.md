# SetAbilityBonusLimit(int)

Sets the ability bonus limit. 
void SetAbilityBonusLimit( int nNewLimit);

### Parameters 

nNewLimit
    The value to set the bonus to.
### Description
Sets the ability bonus limit. The default value is 12. The minimum value is 0. The maximum value is 255.
