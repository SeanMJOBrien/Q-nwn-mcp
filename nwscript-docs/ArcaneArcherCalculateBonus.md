# ArcaneArcherCalculateBonus()
Calculates the enhancement bonus for an Arcane Archer.

### Description
Calculates the enhancement bonus for an Arcane Archer. 
### Remarks
+1 bonus for every odd level. Formula: (Number of class levels + 1) / 2
