# EffectForceWalk()

Forces the creature to always walk. 
effect EffectForceWalk();
#### Description
Forces the creature to always walk. 
#### Remarks
This acts like encumbrance, stealth, detect mode and special zombie walking and the portion of EffectSlow which forces you to slow down to walking speed. 
There are no parameters (such as checkable by GetEffectInteger) for this effect. 
#### Version
This function was added in 1.87.8193.35 of NWN:EE.
