# GetAbilityModifier

# GetAbilityModifier(int, object)
Get a creature's ability modifier for a specified ability. 
int GetAbilityModifier( int nAbility, object oCreature = OBJECT_SELF);
#### Parameters
_nAbility_
 ABILITY_* 
_oCreature_
The creature whose ability modifer is sought. (Default: OBJECT_SELF) 
#### Description
Returns oCreature's ability modifier for nAbility.

1.22
