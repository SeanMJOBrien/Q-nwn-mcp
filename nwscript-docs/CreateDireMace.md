# CreateDireMace

# CreateDireMace(object, object)
Spawns in a Dire Mace as part of the random treasure distribution. 
void CreateDireMace( object oTarget, object oAdventurer);
#### Parameters
_oTarget_
Container to create the item in 
_oAdventurer_
a Player object 
#### Description
Creates a Dire Mace in the container as part of the treasure distribution system. 
#### Remarks
Found in nw_o2_feat.nss This can be used to create the item in any object with an inventory. 
#### Requirements
#include " nw_o2_feat "
