# CreateDivineScroll

# CreateDivineScroll(object, object, int)
Creates a divine scroll as part of the treasure 
void CreateDivineScroll( object oTarget, object oAdventurer, int nModifier = 0);
#### Parameters
_oTarget_
Object to create item on. 
_oAdventurer_
A player object 
_nModifier_
tweak to increase treasure value (Default: 0) 
#### Description
This fuction creates a Divine Scroll in the container as part of the NWN treasure system 
#### Remarks
Found in nw_o2_coninclude.nss This can be used to create the item in any object with an inventory. 
#### Requirements
#include " nw_o2_coninclude "

1.62
