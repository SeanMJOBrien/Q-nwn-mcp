# GetObjectVisibleDistance(object)

Gets oObject's visible distance, as set by SetObjectVisibleDistance(). 
float GetObjectVisibleDistance( object oObject);
#### Parameters 

oObject
    The object to get the visibility distance for.
#### Description
Gets oObject's visible distance, as set by SetObjectVisibleDistance(). Returns -1.0f on error
