# NuiGetUserData(object, int)

Get the userdata of the given window token. 
json NuiGetNthWindow( object oPlayer, int nToken);
### Parameters 

oPlayer
    The player to get user data for 

nToken
    window token
#### Description
Get the userdata of the given window token. 
#### Remarks
Returns JsonNull if the window does not exist on the given player, or has no userdata set. 
#### Version
This function was added in 1.85.8193.31 of NWN:EE.
