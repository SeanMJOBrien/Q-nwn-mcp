# NuiGetEventArrayIndex()

Get the array index of the current event. 
int NuiGetEventArrayIndex();
#### Description
Get the array index of the current event. 
#### Remarks
This can be used to get the index into an array, for example when rendering lists of buttons. Returns -1 if the event is not originating from within an array. 
#### Version
This function was added in 1.85.8193.31 of NWN:EE.
