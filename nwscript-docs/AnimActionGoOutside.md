# AnimActionGoOutside()
Leave area if appropriate. 
int AnimActionGoOutside();

### Description
Leave area if appropriate. This only works for NPCs that entered an area that contains a waypoint with a tag of either NW_TAVERN or NW_SHOP. If the NPC entered through a door, they will exit through that door.
