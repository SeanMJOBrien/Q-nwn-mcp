# AnimInitialization()
General initialization for animations. 
void AnimInitialization();

### Description
General initialization for animations. 
### Remarks
Initializes the following flags and settings: 
  * Sets the caller's animation flag for NW_ANIM_FLAG_IS_ACTIVE and NW_ANIM_FLAG_INITIALIZED.
  * Calls CheckIsCivilized().
