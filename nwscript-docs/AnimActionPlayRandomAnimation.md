# AnimActionPlayRandomAnimation()
Play random animation. 
void AnimActionPlayRandomAnimation();

### Description
Play random animation. 
### Remarks
This appears to play a random animation dependent on a nearby tagged object. The tags the script looks for are NW_TAVERN, NW_HOME, and NW_ALTAR.
