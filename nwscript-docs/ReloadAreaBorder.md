# ReloadAreaBorder(object)

All clients in oArea will reload the inaccessible border tiles. 
void ReloadAreaBorder( object oArea);
#### Parameters 

oArea
    The area for which to reload boundary tiles.
#### Description
All clients in oArea will reload the inaccessible border tiles. This can be used to update the edge tiles after changing a tile with SetTile().
