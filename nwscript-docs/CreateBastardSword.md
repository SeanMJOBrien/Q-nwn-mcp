# CreateBastardSword

# CreateBastardSword(object, object)
Creates a Bastard sword for the containers treasure 
void CreateBastardSword( object oTarget, object oAdventurer);
#### Parameters
_oTarget_
Container to create the item in 
_oAdventurer_
a Player object 
#### Description
Spawns in a magical weapon of questionable leiniege as part of the random treasure distribution. 
#### Remarks
Found in nw_o2_feat.nss This can be used to create the item in any object with an inventory.
