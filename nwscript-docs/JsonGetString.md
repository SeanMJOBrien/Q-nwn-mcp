# JsonGetString(json)

Returns a string representation of the json value. 
string JsonGetString( json jValue);
### Parameters 

jValue
    The json to return as a string.
#### Description
Returns a string representation of the json value. 
#### Remarks
Returns "" if the value cannot be represented as a string, or is empty. NB: Strings are decoded from UTF-8 to the game-local charset. 
#### Version
This function was added in 1.85.8193.31 of NWN:EE.
