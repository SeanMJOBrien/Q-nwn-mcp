# GetGamePauseState()

Returns >0 if the game is currently paused. 
int GetGamePauseState();
#### Description
Returns >0 if the game is currently paused: 
```
0: Game is not paused.
1: Timestop
2: Active Player Pause (optionally on top of timestop)

```
