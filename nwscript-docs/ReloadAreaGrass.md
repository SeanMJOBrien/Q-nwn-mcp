# ReloadAreaGrass(object)

All clients in oArea will reload the area's grass. 
void ReloadAreaGrass( object oArea);
#### Parameters 

oArea
    The area for which to reload grass.
#### Description
All clients in oArea will reload the area's grass. This can be used to update the grass of an area after changing a tile with SetTile() that will have or used to have grass.
